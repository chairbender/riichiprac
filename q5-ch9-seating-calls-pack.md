# Q5 — ch. 9 seating and call replay pack

Implementation unit Q5 of the replay-first rollout
([`replay-first-rollout.md`](replay-first-rollout.md) → *Wave 2*). This is the
fourth chapter pack (after ch. 8 defense, ch. 7 riichi/dama and ch. 5 value): the
ch. 9 **seating and call** family — the valueless-wind discard order and the
concealed quad — mined from the same 1,542-game AI self-play corpus and
classifier v3.

**Shipped artifact:** `frontend/public/scenarios/`, pack
`replay.ch9-seating-calls.2026-11`, **629 reviewed bases, 0 variants,
363,061 bytes**, two lessons across ch9.3/ch9.4. Both clear the 40-base coverage
floor, so both become **replay-default**. The three thin kan/call lessons
(`shouminkan_decision` 19, `daiminkan_decision` 8, `meld_or_not` 0 measured
bases) are **not shipped**; they stay generated by default until corpus growth
`C9`.

`wind_discard_order` and `ankan_decision` are the measured-supply decision: 567
and 62 shipped bases. The other three were selected into the review queue on
purpose, dispositioned, and then **dropped by the 40-base floor in assembly**
(27 `lesson_too_small` drops: 19 `shouminkan_decision` + 8 `daiminkan_decision`;
`meld_or_not` had no stable candidate at all). Their generated lessons remain
the default, so nothing thin ever deals as a replay row.

The shipped-count differences between selected and shipped are assembly's
actor-hand dedupe (33 `wind_discard_order` + 2 `ankan_decision`), not lesson
floors.

## Pipeline

```bash
export RIICHI_DATA_DIR="$HOME/riichiprac-data/q2-ch8-defense-2026-11"
BIN=target/release/mine_replays
cargo build --release --features miner --bin mine_replays

# 1. Labels are classifier v3 from B4 (the one label pass already ran); this
#    pack reuses them, so it does not re-evaluate Mortal. Weights: AGENTS.md
#    §5c (not needed for a stable-book selection or a book-only transform).

# 2. Select one section-scoped queue. All five ch. 9 lessons are named so the
#    thin ones are measured rather than silently excluded; assembly applies the
#    floor afterwards. `--size 3000` raises the family quotas above this
#    chapter's 798-candidate supply, and `--held-out-share 0.02` keeps the QA
#    split at 60 items instead of eating a fifth of a small chapter.
$BIN --data-dir "$RIICHI_DATA_DIR" select \
  --pack-id replay.ch9-seating-calls.2026-11 \
  --size 3000 --held-out-share 0.02 --seed q5-ch9-2026-11 \
  --section ch9 \
  --lesson wind_discard_order,ankan_decision,shouminkan_decision,daiminkan_decision,meld_or_not \
  --stable-book-only \
  --corpus-family mortal_mirror,mortal_sampling_sweep,akochan_tactics,akochan_vs_mortal,heterogeneous_table \
  --max-per-replay 2 --extracted-only --workers 0 --progress \
  --max-section-share 0.95 --max-kind-share 0.95 --max-turn-share 0.95 \
  --json > testdata/reports/q5-ch9/selection-report.json

# 3. Mechanical review (chapter-scoped). The ch9 ready-hand rule is
#    lesson-scoped to wind_discard_order: the kan/call lessons are reactions
#    where tenpai is intrinsic. Then bulk dispositions.
python3 scripts/review-q2-queue.py \
  "$RIICHI_DATA_DIR/reviews/replay.ch9-seating-calls.2026-11/review-queue.jsonl" \
  --chapter ch9 --verdicts-out testdata/reports/q5-ch9/verdicts.json \
  > testdata/reports/q5-ch9/mechanical-review.json
$BIN --data-dir "$RIICHI_DATA_DIR" review --pack replay.ch9-seating-calls.2026-11 \
  --verdicts testdata/reports/q5-ch9/verdicts.json --json \
  > testdata/reports/q5-ch9/review-report.json

# 4. Sampled content sheet for the human sign-off. All 91 kan/call bases are
#    included because those lessons are the thin ones.
python3 scripts/sample-review-sheet.py \
  "$RIICHI_DATA_DIR/reviews/replay.ch9-seating-calls.2026-11/review-queue.jsonl" \
  --sample 220 --per-lesson 30 --per-family 20 --include-all-below 120 \
  --seed q5-ch9-2026-11 --out-json testdata/reports/q5-ch9/review-sample.json \
  > testdata/reports/q5-ch9/review-sample.md

# 5. Persist the reviewed bases (variants are disabled by product decision;
#    the stage still runs its label-preservation check).
$BIN --data-dir "$RIICHI_DATA_DIR" transform \
  --pack-id replay.ch9-seating-calls.2026-11 --variants 1 \
  --seed q5-ch9-2026-11 --generated-at 2026-11-20T00:00:00Z \
  --workers 0 --progress --json \
  > testdata/reports/q5-ch9/variant-report-disabled.json

# 6. Assemble the reviewed bases only, drop duplicate actor hands and the
#    below-floor kan/call lessons, audit, and publish all five hosted packs.
$BIN --data-dir "$RIICHI_DATA_DIR" pack assemble \
  --pack replay.ch9-seating-calls.2026-11 \
  --queue "$RIICHI_DATA_DIR/reviews/replay.ch9-seating-calls.2026-11/review-queue.jsonl" \
  --no-variants --unique-hands --min-bases-per-lesson 40 --max-scenarios 2000 \
  --licence CC-BY-4.0 --attribution "Ch.9 seating/calls pack. <corpus attribution, see the pack>" \
  --generated-at 2026-11-20T00:00:00Z --commit q5-ch9-2026-11 --json \
  > testdata/reports/q5-ch9/assembly-report.json
$BIN --data-dir "$RIICHI_DATA_DIR" pack publish \
  --packs replay.ch9-seating-calls.2026-11,replay.ch5-values.2026-11,replay.ch7-riichi-dama.2026-11,replay.ch8-defense.2026-11,replay.ch8-defense-multi-threat.2026-11 \
  --updated-at 2026-11-20T00:00:00Z --json \
  > testdata/reports/q5-ch9/publish-report.json
node scripts/check-pack-hosting.mjs
node scripts/check-ch8-pack.mjs --allow-no-variants
node scripts/check-ch8-pack.mjs --pack replay.ch8-defense-multi-threat.2026-11 --allow-no-variants
node scripts/check-ch8-pack.mjs --chapter ch7 --allow-no-variants
node scripts/check-ch8-pack.mjs --chapter ch5 --allow-no-variants
node scripts/check-ch8-pack.mjs --chapter ch9 --allow-no-variants
node scripts/replay-coverage-report.mjs --json > testdata/reports/q5-ch9/coverage.json
```

The publish command lists all five packs on purpose: `--packs` replaces the
hosted set with exactly the ids given, so omitting any older pack would prune
its body.

## Selection

Machine-readable report:
[`testdata/reports/q5-ch9/selection-report.json`](../testdata/reports/q5-ch9/selection-report.json).

- 14 workers, 56 min 4 s wall (three passes over 1,542 replays).
- Funnel: 1,542 parsed/valid → 787,052 decisions → 646,776 trigger hits →
  113,094 book matches → **798 gate passes** → 60 held out → **691 selected**.
- 135 selection attempts (47 candidates) were skipped by `--max-per-replay 2`;
  0 slots came from the relaxed fill and 0 selected scenarios were beyond a
  section/kind/turn cap (`cap_relaxed` 0).
- Section mix: ch9.3 91, ch9.4 600. Decision-kind mix: 683 `self_turn` and
  8 `call`; turn mix: early 611, mid 49, late 31. The section, kind and turn
  caps were not binding.
- Corpus mix (no `--corpus-cap`): `mortal_mirror` 362,
  `mortal_sampling_sweep` 316, `akochan_vs_mortal` 5,
  `heterogeneous_table` 5, `akochan_tactics` 3.
- The scope rejected 65,345 out-of-scope and 46,951 contested labels, exactly
  as the stable-book filter requires.
- Selection deduped 24 exact states. The `book` family supplied 390 of the 691
  (the quota was 900 and the chapter's 738 post-held-out candidates were
  exhausted); coverage 195, placement 64, close_call 35, speed_value 5,
  table_read 2. There are no contested/mortal_best/mistake candidates because
  the pack is stable-book only.

**Why the thin lessons were selected but not shipped.** Selecting all five
lessons is the measurement: 19 `shouminkan_decision` and 8 `daiminkan_decision`
bases reached the review queue, and `meld_or_not` produced none (15 book
matches in the corpus, all contested, so 0 stable). Assembly's
`--min-bases-per-lesson 40`
then dropped them by name (27 rows, detail
`lesson ... has N base(s); the pack needs at least 40`), so the app keeps their
generated default. `ankan_decision` (69 stable → 64 selected → 62 shipped) is
the only thin-bucket lesson that clears the floor.

**Held-out QA:** 60 items, disjoint from the pack, deterministic under
`--seed q5-ch9-2026-11` (57 `wind_discard_order`, 2 `ankan_decision`,
1 `shouminkan_decision`), all stable book labels. The held-out set is not part
of the pack and is not dispositioned.

## Review

- **Mechanical review** (`scripts/review-q2-queue.py --chapter ch9`): 691
  items, **691 accepted, 0 rejected**, no invalid reports, 0 duplicate
  exact/visible states, 0 dirty walks. The ch. 9 scope rejects out-of-scope
  sections/lessons, non-book or contested labels, report/lesson mismatches,
  illegal answers, duplicate exact/visible states and dirty walks. Its
  ready-hand rule is **lesson-scoped to `wind_discard_order`** (the only
  slow-hand shape) and keeps ready hands for the kan/call lessons, whose book
  arguments are themselves about tenpai: `daiminkan_decision`'s situations are
  "ready on a good wait" and "ready but outside the three situations",
  `shouminkan_decision` (kakan) applies at 1-away or better, and
  `ankan_decision`/`meld_or_not` argue from block shape and cheapness.
- **Bulk dispositions** (`review --verdicts`): 691 accepted, 0 rejected,
  0 pending, 691 valid reports.
- **Sampled content review:** 220 rows
  ([`review-sample.md`](../testdata/reports/q5-ch9/review-sample.md),
  [`review-sample.json`](../testdata/reports/q5-ch9/review-sample.json)) —
  per-lesson guarantees (30 each), per-family guarantees (20 each) and **all 91
  kan/call bases** (64 `ankan_decision`, 19 `shouminkan_decision`, 8
  `daiminkan_decision`), plus 129 `wind_discard_order` rows. The user sign-off
  is recorded below when received.
