Carved face tuner

Previews the upright 1m tile at 2× with fast samples and a coarse carve grid; "full tile" is the default because the body bevels are part of the light rig. Apply writes into scene-spec.json; run bash tools/render/render.sh for the full set.

Parameters

Lighting
Azimuth is around the tile: 0° front, 90° right, 180° behind, 270° left. Elevation is degrees above horizontal. Two rigs are baked from one scene: the body rig (key + fill) lights the tile blocks, table and background, and the decal rig (parlor strips) lights the carved face. The preset switch picks the decal rig; the key/fill controls always edit the body rig.
Which rig the carved decal is baked under. The body/table rig stays lightRig.

Parlor strips

Each tube is one long thin ceiling fixture; more tubes mean more parallel streaks.
The streak lands where the surface normal is half this (mirror at 2θn), so two elevations give two parallel streaks. Lower puts it nearer the wall/floor junction.
Which walls of the engraving catch it: 0 lights the up-facing walls, 90 the right-facing ones.
Turns the strip about its aim axis: 0 lies along X, 90 stands along Y.
Where the fixture hangs in the front-back direction, in tile units.
Length sets how long the streak is; 1 unit = 28 mm, so 43 units is a 1.2 m tube.
Width sets the streak's cross-section; keep it narrow for a graphic line.
Dim green frontal bounce; it owns the flat face and the floor junction, not the streak.
